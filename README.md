# Lover Is a Day — Lyrics

Site pronto para GitHub Pages. Não usa vídeo: apenas `music.m4a`.

## Sincronização
Os tempos ficam no início do `index.html`, dentro de `window.LYRICS`.
A primeira linha está fixada em **00:42.000**, conforme informado.

Para ajustar qualquer linha, altere somente o número `at`. Ex.: `48.275` = 48,275 segundos.
Você também pode clicar em qualquer linha durante a música para pular diretamente até ela.

## Publicar
1. Extraia o ZIP.
2. Crie um repositório no GitHub.
3. Envie `index.html`, `style.css`, `script.js` e `music.m4a` para a raiz.
4. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
