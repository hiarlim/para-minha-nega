SITE REFEITO DO ZERO — SEM VÍDEO

O MP4 do TikTok foi usado apenas como REFERÊNCIA VISUAL. Ele não faz parte do site.
O site usa somente music.m4a como áudio e recria a tela de letras em HTML/CSS/JS.

Arquivos:
index.html
style.css
script.js
music.m4a

No GitHub:
1. Extraia este ZIP.
2. Envie os quatro arquivos para a raiz do repositório.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.

Observação: os primeiros/últimos timings são aproximações para o lyric display; o visual,
as transições, as linhas anterior/atual/próxima e os corações foram feitos para reproduzir
a aparência do TikTok.
