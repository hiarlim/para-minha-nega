SITE ROSA + AZUL — COM MÚSICA

1. Abra a pasta no VS Code.
2. Abra index.html com Live Server.
3. Clique em ▶ para tocar a música.
4. As frases acompanham o currentTime do áudio.

IMPORTANTE:
O arquivo music.mp3 é o áudio enviado pelo usuário.
Se você alterar a música, ajuste os valores `at` no script.js para os novos momentos das frases.

Para publicar no GitHub Pages, envie index.html, style.css, script.js e music.mp3 para a raiz do repositório.
