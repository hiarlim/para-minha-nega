SITE FEITO DO ZERO — ROSA + AZUL

Esta versão usa o MP4 completo como fonte de áudio + letra. Isso garante que a letra
continue exatamente sincronizada, porque ela já está sincronizada dentro do vídeo.

Arquivos:
- index.html
- style.css
- script.js
- lover-is-a-day.mp4

O MP4 foi comprimido para cerca de 10 MB para permitir o upload pelo navegador do GitHub.

GITHUB PAGES:
1. Crie um repositório público.
2. Envie os quatro arquivos para a raiz.
3. Settings > Pages.
4. Deploy from a branch.
5. Branch: main / (root).
6. Save.
